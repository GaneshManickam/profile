# Profile

A new Flutter project for showcasing a user profile/portfolio.

## 🚀 Features

- **Profile Showcase**: Display user information and portfolio items.
- **Work Experience Gallery**: Highlights projects/companies such as Jio, Zebpay, Auro, and more.
- **Staggered Grid Layout**: Utilizes `flutter_staggered_grid_view` for a modern, masonry-style project gallery.
- **Custom Typography**: Integrated `google_fonts` for consistent and beautiful text styling.
- **External Links**: Easy navigation to external resources (GitHub, LinkedIn, etc.) using `url_launcher`.
- **Responsive Design**: Adapts to different screen sizes.

## 🛠 Tech Stack

- **Flutter**: UI Toolkit
- **Dart**: Programming Language
- **Packages**:
  - `flutter_staggered_grid_view`
  - `url_launcher`
  - `google_fonts`
  - `cupertino_icons`

## 🏃‍♂️ Getting Started

### Prerequisites
- Flutter SDK installed (3.7.2 or higher)
- Android Studio / VS Code / Xcode

### Installation

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd profile
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```

## 📂 Project Structure

- `lib/`: Contains the main application source code.
- `assets/`: Images and static files (configured in `pubspec.yaml`).
- `test/`: Unit and widget tests.
